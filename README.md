# MahaVastu Insights Blog | Acharya Montu Singh

An authentic, modern, and interactive blog website built for **MahaVastu Acharya Montu Singh** using semantic HTML5, Vanilla CSS3, and JavaScript.

## ✨ Features

- **Exact Brand Palette**: Harmonious design adhering to MahaVastu color principles (#EADCB2, #FAF6ED, #D94848, #1A1612, #C8993E).
- **16-Zone Interactive Guide**: Dynamic zone explorer detailing the 16 cardinal directions, elements (Pancha Tattvas), deities, and non-demolition remedies.
- **Dedicated Full Article Reader (`article.html`)**: Complete standalone article reader pages opening via `?id=...` with recommended reads, author profile, and direct WhatsApp consult integration.
- **Real-time Live Search & Elemental Filters**: Search by directional zone, element (Water, Fire, Earth, Space), or keywords.
- **Acharya Montu Singh Credentials**: Highlights his mentorship by Dr. Khushdeep Bansal, 7-Star Certification, Maharashtra Gaurav Award, and World Book of Records recognition.
- **Direct WhatsApp & Phone Booking**: Integrated quick inquiry links for Mumbai & Chennai consultations (+91 7998566666).

## 🚀 Running Locally

Simply open `index.html` in any modern web browser or run:

```bash
# Using Python
python -m http.server 8080

# Or with Node
npx serve .
```

Then visit `http://localhost:8080` in your browser.
